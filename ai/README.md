# ai/ — NPC: база знаний, карточки, движок, память

Владелец: Матвей. ТЗ: `docs/tz/matvey-ai.md`, решения: `docs/DECISIONS.md`.

## Как устроено

На каждый `ai.say()`: факты из базы (с учётом памяти игрока) → промпт → локальная Ollama стримом →
если модель молчит дольше `timeoutMs` (6 с), отвечает шаблон из карточки, который игрок ещё не слышал → память обновляется.

| Файл | Что делает |
|---|---|
| `src/index.ts` | `createAi()`: выбор фактов, адаптация, outcome по тону, шаблоны |
| `src/prompt.ts` | Промпт для модели |
| `src/ollama.ts` | `POST /api/chat` стримом, таймаут на первый токен |
| `src/memory.ts` | Память игрока в `ai/memory/<playerId>.json` (не в git) |
| `src/text.ts` | Поиск фактов по словам вопроса, тон игрока (грубость / паника / спокойствие) |
| `src/cli/chat.ts` | `npm run chat -- papa` |

Адаптация: факт уже рассказан → «я уже говорил» и другой вариант из `explanations`; раньше ошибался в навыке → напомнит заранее;
встречал в прошлом прохождении → узнаёт (`recognize`); грубость → Ваня паникует (`outcome: panicked`).
Шаблоны, которые игрок уже слышал, помечаются в `memory.toldFacts` ключами `tpl:<npc>.<event>.<n>`.

## Как заполнять базу знаний

`knowledge/<навык>.json` — массив фактов: `id`, `skill`, `fact`, 2–3 `explanations` (правило / пример / что будет, если),
`mistakes` (код ошибки → почему опасно), `source` (`title` + `url`).
**Без `source.url` факт не идёт в игру**: `npm run chat` показывает, у каких фактов ссылки нет.
`knowledge/triage.json` — не факты, а порядок сортировки для сценария Юры (D-20).

## Чат в консоли

```bash
npm run chat -- papa                       # из корня репы
AI_MODEL=qwen2.5:7b-instruct npm run chat -- vanya
```
Команды: текст — свободный вопрос; `/event quake_started`; `/mistake cover cover_window`; `/mem`; `/run` — новое прохождение; `/quit`.
