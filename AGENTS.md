# Правила для агентов (Claude Code / Codex)

Игра для хакатона: 3D-кооператив в браузере про эвакуацию при землетрясении и первую помощь.
Команда из 4 человек, 2 дня. **Главное: не ломать чужие модули и main.**

## Прежде чем писать код

1. Прочитай `docs/tz/README.md` и ТЗ своего человека в `docs/tz/`.
2. Прочитай контракты в `shared/src/` (ids.ts, world.ts, ai.ts, scenario/types.ts, minigame.ts, net.ts).
3. Прочитай `docs/DECISIONS.md` — принятые решения. Если решение расходится с ТЗ, верно решение.
4. Задачи бери из `docs/BACKLOG.md` (свой раздел, сверху вниз). Сделал — отметь `[x]` в том же коммите.

## Зоны (работай только в своей)

| Папка | Владелец |
|---|---|
| `ai/` | Матвей |
| `shared/src/scenario/` (кроме types.ts), `client/src/minigames/`, `client/src/debrief/` | Юра |
| `world/` (данные мира, ассеты) | Никита |
| `client/src/world/` (отрисовка, графика) | Юра (D-63) |
| `server/`, `client/src/core/`, `shared/src/*.ts`, `shared/src/scenario/types.ts`, конфиги, CI, `package.json` в корне | Егор (лид) |

Если для задачи нужно изменить файл вне своей зоны или контракт в `shared/src/` — **остановись и скажи человеку**, он договорится с лидом. Не обходи контракт «временно».

## Жёсткие правила

- Всё работает **без интернета**. Никаких облачных API, CDN, шрифтов и моделей по ссылке. ИИ — только локальная Ollama на сервере.
- Новые зависимости — только с согласия лида. Предпочитай то, что уже есть.
- TypeScript strict, без `any` без причины.
- `shared/` — чистый TypeScript: без React, без Node API, без сети.
- Сценарий (`shared/src/scenario/`) — чистые функции: без `Date.now()`, `Math.random()`, мутаций входных данных.
- Тексты для игрока — на русском.
- Перед коммитом из корня: `npm run check`. Красное — чини, не коммить.
- **Пушим сразу в main** (D-61, время жмёт). Порядок: `npm run check` зелёный → `git pull --rebase` → ещё раз `npm run check` → `git push`. Красное — не пушить.
- Коммиты маленькие и частые, только своя зона. Правка контракта `shared/src/*.ts` — только через Егора.

## Команды

```bash
npm install            # из корня
npm run check          # типы + тесты всех модулей
npm run world          # пересобрать чанки мира
npm run chat -- papa   # консольный чат с NPC
```
