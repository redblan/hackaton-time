# Решения и открытые вопросы

**Единый источник правды для договорённостей.** Если решение здесь расходится с ТЗ или с чатом — верно то, что здесь.
Агенты читают этот файл перед работой (см. `AGENTS.md`).

Правила:
- Решения пишет и меняет **лид** (Егор). Решение = одна-две строки: что решили и кого касается.
- Вопрос может добавить **любой** в раздел «Открытые вопросы»: кто спрашивает, кому вопрос.
- Решение не переписываем задним числом: если передумали — новая запись «вместо D-xx».
- Отметка **[контракт]** = нужно поменять `shared/src/`; до правки это обещание, а не код.

## Решения

### Инфраструктура и демо

| # | Решение | Кого касается |
|---|---|---|
| D-01 | Сервер — ноут Егора (48 ГБ): бэкенд, Postgres, Ollama. Клиенты — только браузер | все |
| D-02 | На демо два варианта: сначала по Wi-Fi на нескольких ноутах, потом Wi-Fi выключен и одиночный режим на сервере | все |
| D-03 | ИИ только локально (Ollama). Облачные API запрещены. Модель на сервере `qwen2.5:7b-instruct`, на ноутах разработчиков — 3B | Матвей, Егор |
| D-04 | Связь между игроками и разговор с NPC — текстом. Голос — суперфича, если останется время | все |
| D-05 | Если БД недоступна — сервер работает с хранилищем в памяти, игра не падает | Егор |

### ИИ и данные (Матвей)

| # | Решение |
|---|---|
| D-20 | Сортировка задаётся группами в `ai/knowledge/triage.json`, названия строго из `VictimKind` (`bleeding`, `cpr`, `unconscious`, `scared`, `light_injury`). Временно: `[["bleeding"], ["cpr","unconscious"], ["scared"], ["light_injury"]]` до подтверждения по 220н (Q-01) |
| D-21 | Пострадавший в опасной зоне (провод, газ) не входит в очередь помощи, пока зона не безопасна: сообщить в 112 и бригаде |
| D-22 | Ошибка сортировки — только если выбран пострадавший из группы хуже, чем лучшая из оставшихся; отсутствующие в прохождении типы пропускаются |
| D-23 | Слоты 112: `address`, `what`, `victims`, `condition` — всегда; `trapped` — при флаге `lift_*`; `fire` — при `fire_f*`; `hazard` — при `wire` или `gas` |
| D-24 | Передача бригаде: `victims`, `condition`, `actions`, `tourniquet_time`, `trapped`, `fire`, `hazard`. Условность как в D-23; `tourniquet_time` — только если накладывали жгут. **[контракт]** добавить `condition`, `actions` в `HANDOVER_ITEMS` |
| D-25 | Outcome диалогов: Ваня и напуганный пострадавший — `calmed` / `panicked`; Валентина — `calmed` / `panicked` / `agreed_to_go` / `left_behind`; диспетчер — `slots_complete` / `slot_missing:<слот>`; бригада — `handover_complete` / `handover_missing:<пункт>`. **[контракт]** добавить `left_behind` в `DIALOG_OUTCOMES` |
| D-26 | `left_behind` шлёт сервер (не ИИ): игрок ведёт Валентину и отошёл дальше 8 м, не чаще раза в 5 с |
