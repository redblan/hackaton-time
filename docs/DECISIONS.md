# Решения и открытые вопросы

**Единый источник правды для договорённостей.** Если решение здесь расходится с ТЗ или с чатом — верно то, что здесь.
Агенты читают этот файл перед работой (см. `AGENTS.md`).

Правила:
- Решения пишет и меняет **лид** (Егор). Решение = одна-две строки: что решили и кого касается.
- Вопрос может добавить **любой** в раздел «Открытые вопросы»: кто спрашивает, кому вопрос.
- Решение не переписываем задним числом: если передумали — новая запись «вместо D-xx».
- Отметка **[контракт]** = нужно поменять `shared/src/`; до правки это обещание, а не код.

| # | Решение | Кого касается |

### Ответы Юре (31.10, 13:30)

| # | Решение |
|---|---|
| D-40 | В `RunState` есть `timers: Record<string, number>` (момент старта таймера, мс игрового времени). Таймеры в `facts` не храним |
| D-41 | Сборы засчитываются только по мини-игре `go_bag`: она открывается эффектом на этапе `pack`. Интерактивы `item_*` редьюсер не обрабатывает, это декор |
| D-42 | `light_injury` сегодня не выдаётся (тип остаётся в контракте на будущее). Укрытия «под люстрой» нет: хватает `cover_window` и `cover_wardrobe` |
| D-43 | Газ на кухне есть всегда (часть этапа `pack`). Флаг `gas` — опасность во дворе вместо провода |
| D-44 | Переходный балкон только на 4-м этаже, поэтому обвал только `collapse_f4` |
| D-45 | Дым засчитан: вошёл в `z_smoke` с `water` в инвентаре. Сопровождение засчитано: `agreed_to_go` и дошёл до `z_safe_area`; ошибки — D-18. Отдельных событий (присел, мокрая ткань, кот) сегодня нет |
| D-46 | Никита ставит `z_collapse` на сам провал (обломки, пролёт), а не на площадку перед ним. Вход в зону — одна ошибка за прохождение |
| D-47 | Разговор с Ваней и Валентиной начинается по interact (`elevator_shaft`, `neighbor_door`). Звонок 112 сегодня стартует автоматически на этапе `call_112` (после входа в `z_safe_area`) |
| D-48 | Табличку `address_plate` редьюсер не учитывает: адрес проверяет диспетчер по тексту. Табличка нужна игроку, чтобы адрес узнать |
| D-49 | Разбор заканчивается по interact `brigade` или через 60 с. После `runEnd` клиент показывает итог и кнопку «Сыграть ещё» (делает Егор) |
| D-50 | `tick` шлёт сервер раз в секунду. `at` во всех событиях — **игровое время** в мс от старта прохождения. Пока в комнате нет подключённых игроков, игровое время стоит (пауза), после перезахода идёт дальше |
| D-51 | Кооп: сценарные этапы — Юра, сеть и синхронизация — Егор. Проектируем завтра утром. Сегодня приоритет — соло от начала до конца для демки |
