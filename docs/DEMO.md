# Демо: чек-лист (D-02)

Сервер — ноут Егора. Клиенты — только браузер (Chrome).

## За час до демо (интернет ещё есть)

- [ ] `git pull && npm install` — зависимости на месте.
- [ ] Ollama запущена, модель скачана: `ollama list` показывает `qwen2.5:7b-instruct` (D-03). Прогрев: `npm run chat -- papa`, один вопрос.
- [ ] Postgres: `npm run db` (docker) — или без него, сервер работает в памяти (D-05).
- [ ] `npm run world` — чанки собраны (30 шт.), `npm run check` зелёный.

## Вариант 1: по Wi-Fi на нескольких ноутах

1. Все ноуты в одной сети (не гостевой Wi-Fi и не раздача с телефона — они часто изолируют устройства). VPN на сервере выключить.
2. Сервер: `npm run start` → собирает клиент и пишет адреса `https://<ip>:3000`.
3. Клиенты: открыть `https://<ip>:3000`, принять самоподписанный сертификат («Дополнительно → Перейти»). Проверка: `https://<ip>:3000/api/health` → `{"ok":true,...}`.
4. Вход (любое имя/пароль) → «Кооператив на двоих» → каждый берёт свою роль.

## Вариант 2: Wi-Fi выключен, одиночная игра на сервере

1. Выключить Wi-Fi на сервере. `npm run start` (или уже запущенный продолжает работать).
2. `https://localhost:3000` → «Одиночная игра».
3. F3 — показать жюри «под капотом»: загружено 2–3 из 30 чанков (≤ 10%), реплики `llm` от локальной модели, что NPC помнят об игроке.

## Что показать жюри (по пунктам ТЗ)

| Пункт | Как показать |
|---|---|
| Подгрузка мира ≤ 10% | HUD «загружено N/30», F3 — список чанков меняется при спуске по лестнице |
| ИИ-агенты, не скрипт | Спросить папу дважды одно и то же — ответ другой; F3 — источник `llm`, факты в памяти |
| Память и адаптация | Второе прохождение тем же игроком: лобби показывает слабые навыки, генератор их подкидывает, NPC узнаёт |
| Без интернета | Вариант 2 целиком |
| Шифрование | `https://`, вход по токену, сокет без токена отклоняется |
| Кооп по сети | Вариант 1: двое видят друг друга, рация, Валентина идёт за игроком |
| Обучение | Мини-игры с разбором ошибок, разбор Громова в конце |

## Если что-то сломалось

- Не открывается с другого ноута → `ipconfig getifaddr en0` (новый IP?), VPN, та же ли сеть.
- NPC отвечают шаблонами (`шаблон` у реплики) → Ollama не запущена или не успевает: `ollama ps`. Игра при этом работает.
- Сервер упал → `npm run start` ещё раз: комнаты восстановятся из БД, игроки вернутся на свои места при перезаходе.
