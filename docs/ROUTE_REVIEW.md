# Разбор маршрута — Никита

Вся функция реализуется Никитой по прямому поручению пользователя, включая
контракты, сервер и экран клиента. Ветка: `nikita/route-review`.

После завершения игры на экране результата появляется схема. Можно выбрать
игрока, двор или этаж 1–9, перемещать время и нажимать красные точки ошибок.
В лобби кнопка «Маршрут последнего прохождения» открывает последний сохранённый
разбор текущего пользователя. Сетевой маршрут доступен только после входа:
`GET /api/me/route`, заголовок Authorization Bearer.

Контракт: `shared/src/route.ts`, поле `RunSummary.route` необязательное для
совместимости. Сервер собирает компактную схему из имеющихся чанков: стены,
опасные зоны и место сбора. Полные 30 чанков на клиент не передаются.
Оранжевые области — действовавшие опасности с временем появления. Схема условная:
огонь показан зоной дыма, газ — областью вокруг облака. Статические опасности
из конфигурации действуют с начала прохождения. Это не расчёт идеального пути.

Координаты берутся на сервере из тех же сообщений движения, что использует игра.
Обычно записывается не более одной точки в секунду при смещении от 0.25 м;
смена этажа, ошибки и завершение фиксируются дополнительно. После разрыва более
10 секунд или скачка более 12 м начинается новый сегмент, расстояние скачка не
суммируется. Длина приблизительная: мелкие повороты между отсчётами не учитываются.
Лимиты: 7200 точек и 500 ошибок на игрока; при исчерпании точек показано сообщение.

Точка ошибки — серверная позиция игрока в момент записи `journal`, включая
пропуски (`missed`), а не обязательно место опасности. Карточки объясняют это.
Советы выбираются по навыку; для мини-игр предлагается повторить её инструкцию.

Незавершённый маршрут и времена флагов входят в существующий снимок комнаты,
который периодически сохраняется. Завершённый результат остаётся в снимке;
последний разбор каждого участника отдельно сохраняется в `route_reviews`
(JSONB, таблица создаётся автоматически при запуске). Сохраняется командный
маршрут для участников этой комнаты; посторонние пользователи его не получают.
При отсутствии PostgreSQL всё работает в MemStore до перезапуска процесса.

Проверки: `npm run check`, `npm run build`. Тесты проверяют отсчёты и разрывы,
лимиты, восстановление снимка, активацию опасностей, передачу результата через
настоящий сокет и сохранение отчёта, HTML/SVG схемы. Живая PostgreSQL и визуальное
прохождение браузером требуют отдельной проверки в окружении демо.
