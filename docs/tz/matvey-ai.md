# ТЗ: Матвей — ИИ и NPC

**Твоя зона:** папка `ai/` (и только она).
**Контракт:** `shared/src/ai.ts` (`NpcRequest`, `NpcResponse`, `PlayerMemory`, `AiModule`), словарь `shared/src/ids.ts` (`NPC_IDS`, `NPC_EVENTS`, `SKILLS`).
**Зачем:** это главный пункт ТЗ хакатона про ИИ. Жюри будет говорить с NPC и проверять, что они не скрипт: помнят игрока, не повторяются, объясняют по-разному. И что всё работает без интернета.

## Что сделать

### P0 — к вечерней демке

1. **База знаний** `ai/knowledge/<тема>.json` — массив фактов:
   ```json
   {
     "id": "cover.where",
     "skill": "cover",
     "fact": "Во время толчков на верхних этажах не бегите на лестницу: укройтесь подальше от окон и того, что может упасть.",
     "explanations": [
       "Правило: ...",
       "Пример: ...",
       "Что будет, если: ..."
     ],
     "mistakes": { "cover_window": "Почему у окна опасно: ..." },
     "source": { "title": "МЧС России — памятка ...", "url": "https://..." }
   }
   ```
   Темы по навыкам из `SKILLS`: `cover`, `go_bag`, `gas`, `elevator`, `smoke`, `route`, `escort`, `exit_building`, `yard_hazard`, `call_112`, `triage`, `bleeding`, `cpr`, `recovery_position`, `psych_support`, `aftershock`, `handover`.
   **У каждого факта ссылка на официальный источник (МЧС, Минздрав). Без ссылки факт в игру не идёт.** Открой источник сам и проверь, что агент не выдумал.
2. **Карточки NPC** `ai/npcs/<npcId>.json`:
   ```json
   {
     "id": "papa",
     "name": "Сергей",
     "role": "Отец игрока, инженер",
     "personality": "Собранный, говорит коротко, заботливый, немного ворчит",
     "speech": "Короткие фразы, на «ты», без канцелярита. Максимум 3 предложения.",
     "events": {
       "quake_started": { "goal": "Велеть укрыться, не бежать на лестницу", "facts": ["cover.where"], "templates": ["...", "...", "..."] },
       "quake_over_pack": { "goal": "...", "facts": ["go_bag.items", "gas.smell"], "templates": ["..."] }
     }
   }
   ```
   P0 — карточки `papa`, `vanya`, `mihalych`, `gromov`. Минимум 3 шаблона на событие: они нужны, когда модель недоступна.
3. **Движок** `ai/src/index.ts` → `createAi(opts): AiModule` по контракту.
   - Собирает промпт: карточка + цель события + факты (только из базы!) + память игрока + последние реплики.
   - Зовёт Ollama (`POST {ollamaUrl}/api/chat`, `stream: true`) по `fetch`, без внешних SDK.
   - Таймаут (по умолчанию 6 с) или ошибка → шаблон из карточки, который этот игрок ещё не слышал.
   - Обновляет память: какие факты прозвучали, какой вариант объяснения использован.
4. **Память** `ai/src/memory.ts` — `MemoryStore` на JSON-файлах в `ai/memory/<playerId>.json` (папка в .gitignore). Потом Егор подменит на БД, интерфейс не меняется.
5. **Консольный чат** `npm run chat -- papa` — поговорить с NPC в терминале и посмотреть память.

### P1 — завтра

6. **Диспетчер 112** `ai/src/dispatcher.ts` — конечный автомат. Слоты — `DISPATCHER_SLOTS` из `ids.ts`:

   | Слот | Что должен сказать игрок |
   |---|---|
   | `address` | адрес дома (есть в `context.address`, игрок видит его на табличке) |
   | `what` | что случилось: землетрясение, обрушение |
   | `victims` | сколько пострадавших |
   | `condition` | их состояние: кровотечение, без сознания, не дышит |
   | `trapped` | люди в лифте или под завалом |
   | `fire` | есть ли пожар / задымление и где |
   | `hazard` | опасности: оборванный провод, газ, треснувший козырёк |

   Слоты вытаскиваются из текста игрока регулярками и ключевыми словами, LLM только формулирует вопрос. Ответ: `outcome: "slot_missing:<слот>"` (первый недостающий по порядку таблицы) или `"slots_complete"`, плюс `slots` — что уже собрано.
7. Карточки `valentina`, `dispatcher`, пострадавшие. Передача бригаде (`gromov`): то же, что у диспетчера, но по `HANDOVER_ITEMS` (`victims`, `condition`, `actions`, `tourniquet_time`, `trapped`, `fire`, `hazard`; условность — D-23/D-24 в `docs/DECISIONS.md`) → `handover_missing:<пункт>` или `handover_complete`.

   **Все значения `outcome`** — тип `DialogOutcome` из `ids.ts`, других не придумываем (нужен новый — к Егору):

   | `outcome` | Кто возвращает | Когда |
   |---|---|---|
   | `calmed` | vanya, valentina, victim_*, neighbor_leg | игрок говорит спокойно, поддерживает |
   | `panicked` | те же | грубость, паника, крик в тексте игрока |
   | `agreed_to_go` | valentina | согласилась идти с игроком к выходу |
| `left_behind` | **сервер**, не ИИ | игрок ушёл от Валентины дальше 8 м (D-26) — ИИ его не возвращает |
   | `slot_missing:<слот>` | dispatcher | не хватает слота из `DISPATCHER_SLOTS` |
   | `slots_complete` | dispatcher | все слоты собраны |
   | `handover_missing:<пункт>` | gromov | не хватает пункта из `HANDOVER_ITEMS` |
   | `handover_complete` | gromov | бригада получила всё |

   Нет итога в этой реплике — `outcome` не ставим.
8. Разбор Громова (`event: "debrief"`): получает в `context` журнал ошибок и строит разбор из 3–4 пунктов. Ошибки, которые игрок делал раньше, объясняет **другим вариантом** из `explanations`.

## Адаптация — что именно проверит жюри

- Игрок второй раз спрашивает то же самое → NPC не повторяет слово в слово: «Я уже говорил — коротко: ...» или другой вариант объяснения.
- Игрок раньше ошибался в навыке → NPC заранее напоминает именно про это.
- NPC, которого игрок встречал в прошлом прохождении, его узнаёт (`npc[id].met`).
- Грубость или паника в тексте игрока → NPC реагирует (Ваня паникует сильнее).

## Нельзя

- Ходить в интернет из кода (никаких облачных API, ни DeepSeek, ни OpenAI).
- Трогать файлы вне `ai/`. Нужно поменять контракт в `shared/` — к Егору.
- Ставить тяжёлые зависимости (LangChain и т.п.). Хватает `fetch`.
