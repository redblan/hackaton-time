# ТЗ: Никита — мир

**Твоя зона:** `world/` (генератор, ассеты, чанки) и `client/src/world/` (отрисовка чанка).
**Контракт:** `shared/src/world.ts` (формат чанка, координаты), `shared/src/ids.ts` (`INTERACTABLES`, `ZONES`, `NPC_IDS`, `ROLES`).
**Зачем:** мир — первое, что видит жюри. «Красиво, детализировано, производительно» — это про тебя. И подгрузка по чанкам (≤ 10% мира на клиенте) — пункт ТЗ хакатона.

## Мир

- Девятиэтажка на 2 подъезда + двор. Координаты и сетка — в шапке `shared/src/world.ts`.
- 30 чанков: `e1f1..e1f9`, `e2f1..e2f9` (этажи), `y00..y23` (двор 3 × 4).
- Стиль: яркий низкополигональный мультяшный, как RV There Yet. Тёплые цвета, мягкий свет.

## Что сделать

### P0 — сейчас, пока интернет есть

1. **Скачать CC0-ассеты** в `world/assets/` (glb/gltf): мебель, кухня, двери, лифт, лестница, деревья, машины, детская площадка, столб, люди с анимациями. Источники: Kenney (kenney.nl), Quaternius, KayKit. Список паков и лицензий — в `world/assets/LICENSES.md`.
2. Следи за весом: один чанк — до ~2–3 МБ моделей. Тяжёлое ужимаем (gltf-transform), иначе подгрузка тормозит.

### P0 — к вечерней демке

3. **Генератор** `world/src/build.ts` → `world/chunks/<id>.json` (`npm run world`). Этажи генерируй из шаблона функцией (`floorChunk(entrance, floor)`), а не руками 18 раз.
   - Квартира игрока на этаже старта: комната, кухня, коридор, дверь. Все интерактивы из `INTERACTABLES` про квартиру: `cover_*`, `item_*`, `gas_valve`, `light_switch`, `apartment_door`.
   - Лестничная клетка: лестница вниз, лифт (`elevator_call`, `elevator_shaft`), зоны `z_hall`, `z_stairs`, `z_elevator`.
   - Вариативные объекты через `when`: дым и `z_smoke` на этаже с `when: "fire_f5"` (на каждом этаже-кандидате свой флаг), завал и `z_collapse` — `when: "collapse_f4"`, переходный балкон (`balcony_door`, `z_balcony`) на каждом этаже.
   - 3-й этаж: дверь соседки (`neighbor_door`), NPC `valentina` с `when: "neighbor_valentina"`.
   - Точки появления (`spawn`) для ролей: `inside_top` — в квартире на этаже старта, `inside_mid` — 3-й этаж, `outside` — двор.
4. **Двор**: подъезды с козырьком (`z_canopy_danger`), табличка с адресом (`sign` + `address_plate`), столб с проводом (`z_wire_danger`, `fx: sparks`, `when: "wire"`), детская площадка (`z_safe_area`), места пострадавших (`npc` с `pose: "lie"` + interactable `victim_*`), место бригады (`brigade`).
5. **Отрисовка** `client/src/world/ChunkView.tsx` (после того как Егор зальёт клиент):
   ```ts
   export function ChunkView(props: { chunk: ChunkData; flags: string[] }): JSX.Element
   export function getColliders(chunk: ChunkData, flags: string[]): Aabb[] // для столкновений, их использует Егор
   ```
   Объекты с `when` не из `flags` не рисуются и не сталкиваются. Коробки — инстансингом, если их много. Модели — `useGLTF` из `/assets/...`.

### P1 — завтра

6. Свет и атмосфера: ночь, фонари во дворе, пыль после толчка, дым.
7. Анимации NPC (стоит, лежит, машет), подсветка интерактивов при приближении.

## Как проверить сам (готово, если)

- [ ] `npm run world` создаёт 30 файлов в `world/chunks/`, `npm run check` зелёный.
- [ ] Тест/скрипт-проверка: у каждого чанка верные `bounds`, все `target`/`zone`/`npcId` есть в словарях `ids.ts`, у всех объектов уникальные `id` внутри чанка.
- [ ] До клиента: просмотр чанков в three.js editor (импорт glb) или в песочнице Егора, когда она появится.
- [ ] Чанк этажа с моделями весит не больше ~3 МБ.

## Нельзя

- Тянуть ассеты по ссылкам из интернета в рантайме — всё лежит в `world/assets/`.
- Менять формат в `shared/src/world.ts` самому. Нужно новое поле (`kind`) — к Егору, добавим за 5 минут.
- Трогать сеть, сервер и логику сценария.
