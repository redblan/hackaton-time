# ТЗ: Егор — сервер, клиент, склейка

**Зона:** `server/`, `client/` (кроме `minigames/` и `world/`), контракты `shared/src/*.ts`, CI, конфиги.

## P0 — к вечерней демке

1. **Сервер** `server/`: Node + Express + Socket.IO + Postgres.
   - `POST /api/login` → токен, сокет только с токеном (`auth.token`). HTTPS — самоподписанный сертификат (нужен для микрофона и закрывает пункт ТЗ про шифрование).
   - Комнаты: лобби, выбор режима и ролей, старт.
   - Позиции игроков: приём ~15 Гц, рассылка ~10 Гц.
   - Чанки: читает `world/chunks/*.json`, отдаёт по `chunk:want`, на клиенте ≤ 3 одновременно. Ассеты — статикой `/assets`.
   - Сценарий: держит `RunState`, гоняет `reduce()` Юры на события и `tick` раз в секунду, исполняет эффекты.
   - ИИ: `createAi()` Матвея, стрим реплик игроку. Память — в Postgres (свой `MemoryStore`).
   - БД: игроки, профили навыков, память NPC, сохранение прохождения (этап + позиция) — восстановление после перезахода.
   - Раздача собранного клиента — один адрес `https://<ip>:3000` для всех.
2. **Клиент** `client/`: Vite + React Three Fiber + drei.
   - Вход, лобби, выбор режима.
   - От первого лица (или камера из-за плеча), WASD + мышь, столкновения по `getColliders()`.
   - Менеджер чанков: по позиции просит чанки, выгружает дальние (`dispose`), HUD «загружено 3/30 (10%)».
   - Другие игроки (интерполяция), подсказка «E — ...» у интерактивов, зоны → `enterZone`.
   - HUD: этап и подсказка, реплики NPC (стрим), чат-рация, ввод текста для NPC.
   - Хост мини-игр: по `openMinigame` показывает компонент Юры, результат → `game:event`.
   - Роут `/sandbox` для мини-игр и просмотра чанков.
3. **Демо без сети**: всё на сервере, `npm run start` → открыть `https://localhost:3000`.
