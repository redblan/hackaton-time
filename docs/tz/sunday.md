## Контракты (Егор, первый коммит дня)

| Что | Где | Суть |
|---|---|---|
| `client:metrics` | `net.ts`, клиент → сервер раз в 2 с | `{ fps, ping, chunks, dpr, gpu }`; ping клиент меряет сам (`ping` → `pong`) |
| `world:patch` | `net.ts`, сервер → клиент | `{ chunkId, add: WorldObject[], remove: string[] }` — живое изменение чанка в комнате. Применяется и к уже загруженному чанку, и к тем, что придут потом. Так мир меняют и агенты (Матвей), и админка |
| `prop:move` | `net.ts`, клиент ↔ сервер | `{ id, chunkId, pos, rotY, vel? , holder? }` — переносимые предметы: кто держит/бросил — тот и шлёт, сервер пересылает остальным и держит последнее состояние комнаты |
| `kind: "prop"` | `world.ts` | объект, который можно взять: `{ id, kind:"prop", src?|size, pos, mass, bounce, label }`. Коллизия — коробка, физика на клиенте (Юра) |
| `kind: "crowd"` | `world.ts` | простой NPC: `{ id, kind:"crowd", type:"cat"|"dog"|"pigeon"|"person", pos, route?: Vec3[], seed }` |
| `/admin` | сервер | `GET /api/admin/*` и сокет-неймспейс `/admin` по `ADMIN_PASSWORD` (env; по умолчанию `admin`) |
| Поведение агента | `ai/index.ts` (Матвей) | `getCharacters()` / `setCharacter(npcId, patch)` — характер, настроение, температура, «только шаблоны», разрешённые факты; действует сразу, без перезапуска |
