# hackaton-time — «Толчок»

3D-кооператив в браузере: эвакуация из многоэтажки при землетрясении и первая помощь во дворе. Мультиплеер по LAN, локальные ИИ-агенты, всё работает без интернета.

- **ТЗ и кто что делает:** [`docs/tz/README.md`](docs/tz/README.md)
- **Правила для агентов:** [`AGENTS.md`](AGENTS.md)

```bash
npm install
npm run check
```

Нужно: Node.js 20.9+. Для ИИ на сервере — [Ollama](https://ollama.com) с локальной моделью (скачать заранее).
