# Никита: данные для воскресных задач N11–N14

Источник задач: `docs/tz/sunday.md`. Здание по-прежнему девятиэтажное:
18 этажных чанков двух подъездов и 12 чанков двора, всего 30.

## N11 — переносимые предметы

`src/propPlacements.ts` → `addProps` подключён в `generateWorld` после контракта
Егора 41384f1. В каждом из 18 этажных чанков по 8 предметов (144 всего):
аптечка, фонарь, вода, кружка, две коробки, огнетушитель и стул.
`pos` — мировой центр коробки, `size` — габариты, `mass` — масса,
`bounce` — отскок 0..1. Есть русская `label` и цвет, дополнительных GLB нет.
Предметы лежат на полу в стороне от основного пути: декоративные комод и стол
не являются опорой для физики. Огнетушитель есть на каждом этаже обоих подъездов.

ID уникальны во всём мире: `${chunk.id}-prop-${preset}`; коробки используют
суффиксы `hall-box` и `stair-box`. Старые `prop-first_aid_kit`, `prop-flashlight`,
`prop-water`, `prop-mugs` удалены, соответствующие `item_*` перенесены к новым
позициям. Остальные предметы сборов и мини-игра по D-41 сохранены.

Рендер, взять/нести/бросить и динамическая физика — G11 Юры. В текущем main
ещё нет компонента для отрисовки `prop`, поэтому готовность данных N11
не означает готовность управления предметами. Для проверки расстановки
`world/scripts/walk-check.ts` считает все prop неподвижными твёрдыми коробками:
даже в таком случае они не должны перекрывать эвакуацию.

## N13 — объекты для агентов

`src/requested.ts` добавляет объекты по существующим `when`/`unless`.
Все флаги по умолчанию выключены. Включение флагов — AI/сервер, не генератор.
Мелкие предметы декоративные, не перекрывают путь игрока.

| Флаг | Чанки | Мировые координаты и результат |
|---|---|---|
| `spawn_first_aid` | `e1f6`–`e1f9` | Шкафчик у стола `[4.8, y, 9.7]`, аптечка на полке `[4.8, y + .8, 9.7]`; y — пол этажа |
| `spawn_ladder` | `y00`, `y10` | Лестницы `[11.4, 0, -1.1]`, `[23.4, 0, -1.1]`, в стороне от козырьков и входов |
| `spawn_blankets` | `y12` | Одеяла `[12.8, 0, -25.3]`, вода рядом; у места сбора, в стороне от спауна и качелей |
| `power_on` | `y20` | Тёмная головка фонаря сменяется светлой в `[27, 4.3, -6]` |
| `spawn_exit` | `e1f1` | В южной стене открывается второй проём x=9.1..10.9, высота 2.4 м; основной выход сохранён |

Интеграция Юры для N13: свет по `requested-lamp-on.pos` (в контракте мира нет
`kind: light`); для нового выхода — убрать накладную покраску, внутреннее окно,
подоконник и радиатор у x=10 на первом этаже первого подъезда при `spawn_exit`.
Геометрия/коллизии проёма уже заданы в данных. Декор `Interior` сейчас рисуется
отдельно от чанка и не учитывает этот флаг. Пока он не обновлён, визуально
второй выход нельзя считать готовым.

## N14 — палитра админки

`src/palette.ts`: `PALETTE` — 11 пресетов: аптечка, фонарь, вода, коробка,
огнетушитель, стул, кружка, одеяла, лестница, шкафчик, ограждение.
У каждого есть `id`, русская `label`, общий `size`, основной `color`, `parts`.
Каждая часть задаёт `pos`, `size`, `color`. Координаты локальные: Y=0 — низ,
X/Z — относительно места установки. Никаких дополнительных ассетов/зависимостей.

`paletteObjects(presetId, instanceId, pos, rotY, collide)` превращает пресет
в совместимые `WorldObject` (`box`), поворачивает смещения частей и назначает
уникальные ID с префиксом экземпляра. Админка должна сохранять этот префикс,
чтобы удалять все части одного экземпляра через `world:patch.remove`.

`npm run world` автоматически экспортирует `world/chunks/palette.json`.
Формат — массив этих пресетов; он совместим с `/api/admin/palette` и
размещением пресетов в админке Егора. Загрузчики сервера и корневого walk
исправлены в 41384f1, собственный walk также фильтрует имена файлов.
Клиентский тест `npcRoutes.test.ts` читает только имена чанков и исключает
палитру. Интеграционный тест читает каталог с палитрой и проверяет, что
сервер продолжает загружать ровно 30 чанков.

## Зависимости

Контракты и загрузчики Егора готовы: prop/world:patch/prop:move — 41384f1,
crowd — 0442360. N11–N14 подключены в данных мира; изменения shared не нужны.
Остаются клиентские G11 (предметы) и G15 (свет/отделка выхода) Юры,
включение флагов/патчи по запросу игрока — AI/сервер.

`src/crowdPlacements.ts` содержит 15 жителей двора, 8 животных (4 кошки и
4 собаки), 18 голубей (6 на козырьках) и по 2 соседа в каждом подъезде.
Максимум 8 NPC в чанке. Seed вычисляется из стабильного ID. Маршруты замкнуты
внутри одного чанка; тест проверяет каждый отрезок с учётом габарита тела,
отсутствие пересечений со статическими препятствиями и наличие опоры.
Толпа N12 уже рисуется модулем G12 Юры; `validateWorld` проверяет seed,
маршруты, лимит количества NPC, а также размеры/подписи/физические параметры prop.
