# Мир «Толчка»

`npm run world` создаёт 30 детерминированных чанков; `npm run check` включает тесты мира.
Контракты shared не изменены. Все объекты сейчас процедурные коробки, внешних ресурсов в рантайме нет.

## Интеграция

- Координаты объектов мировые. Двор: колонка 0..2, ряд 0..3 от дома; высота bounds двора 0..6 м.
- Старт inside_top: выбирать spawn только из e1f{config.startFloor}, этажи 6..9. Inside_mid — e1f3, outside — y12.
- Соседи перечислены по приоритету: нижний этаж/выход, верхний этаж, переход в другой подъезд. Ограничение трёх загруженных чанков обеспечивает ядро клиента.
- Лестницы спускаются ниже bounds текущего этажа: для столкновений на переходе нужны оба соседних чанка.
- Все объекты с when, включая зоны и эффекты, нужно фильтровать по flags.
- Адрес в табличках пока учебный: «Учебная улица, 12». Ядро должно согласовать его с RunConfig.address.
- NPC Ваня представлен на этажах первого подъезда как точка разговора у шахты. Клиент не должен трактовать их как разных персонажей.
- Двери представлены точками взаимодействия с открытым проходом: в контракте нет состояния открывания двери.

## Оставшаяся интеграция

В текущем репозитории нет client и его зависимостей. ChunkView, инстансинг, подсветка, ночной свет и анимации требуют клиентского каркаса Егора. Создавать конфигурацию клиента в зоне Никиты запрещено AGENTS.md.

CC0-паки ещё не добавлены; LICENSES.md не заявляет лицензий на отсутствующие модели. Текущая версия соответствует этапу из агентского промпта ТЗ: сначала коробки, затем локальные модели. Визуальный просмотр и проверка проходимости в игровом контроллере ещё требуются после интеграции клиента.
