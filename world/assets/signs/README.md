# План эвакуации (N6)

Оригинальная схема игрового мира, созданная для проекта. Внешних изображений,
шрифтовых файлов и сетевых зависимостей в ассетах нет.

Два стенда у подъездов: `evacuation-e1.glb` и `evacuation-e2.glb`.
На каждом — схема девяти этажей, лестницы двух подъездов, условный обход завала
через переход на четвёртом этаже, выходы и детская площадка (место сбора).
Красная отметка «Вы здесь» различается для каждого подъезда.
Это схема игровой локации, не в масштабе.

PNG встроен в GLB (2.6 × 1.8 м, unlit для читаемости), предпросмотр лежит рядом.
Существующий ChunkView уже поддерживает эти модели; изменения клиента не нужны.
Стенды развёрнуты во двор и расположены слева от козырьков, вне прохода.
Интерактив `building_plan` сохранён; отдельного окна просмотра контракт не предусматривает.

Пересборка на Windows без новых зависимостей:

```powershell
./world/scripts/draw-evacuation-plan.ps1
node world/scripts/build-evacuation-plan.mjs
npm run world
```

Первый скрипт растеризует подписи системным Arial; при других версиях шрифта
пиксели могут отличаться. Для игры используются уже сохранённые GLB.
