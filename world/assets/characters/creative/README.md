# Жители ITHappy (локальный набор)

Источник: [Creative Characters Free](https://ithappystudios.com/free/creative-characters-free/).
Это **не CC0**. См. [правила бесплатных ассетов](https://ithappystudios.com/free-asset-usage-policy/)
и [лицензию](https://ithappystudios.com/type-of-licenses/).
Автор разрешает использование в конечной игре, но запрещает раздачу исходных
ассетов и производных вне конечного продукта. Поэтому GLB исключён из git.
Не добавлять его принудительно и не прикладывать архив заказа к PR.

На компьютере, где собирается демо:

1. Самостоятельно получить бесплатный набор на сайте автора, принять условия.
2. Распаковать GLB-архив в локальную папку.
3. Из корня выполнить:
   `node world/scripts/prepare-creative-characters.mjs "путь/Creative_Character_free.glb"`
4. Перезапустить Vite / пересобрать клиент. Локальный GLB попадёт в конечную
   сборку игры; во время игры интернет не используется.

Если GLB отсутствует, клиент использует прежние CC0-модели KayKit. Для команды
нужен собственный законный доступ к паку; git pull сам модели не скачивает.

Образы, цвета и соответствие NPC описаны в
`client/src/world/characterPresets.ts`. Пожилые жители используют седые волосы,
усы/очки; бабушке добавлены пучок и платок, молодёжи — наушники и кроссовки.
Это стилизованные варианты одного базового тела бесплатного набора.

Скрипт оставляет только нужные детали и клипы, перепаковывает бинарные данные,
проверяет встроенные текстуры. Лежачая поза — последний кадр Death_Backward;
сидячая строится на том же скелете в клиенте. Игра не воспроизводит смерть.
Просмотр всех образов: `/src/world/characters-preview.html` в dev-сервере.
