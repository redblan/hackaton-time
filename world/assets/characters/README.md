# N5 — персонажи для Character.tsx

Две стилизованные человеческие модели **Mage** и **Rogue** из KayKit Adventurers 1.0,
Kay Lousberg, CC0. Это исходные фэнтезийные костюмы, не форма спасателей.
Геометрия, скелет, материалы и встроенные PNG не изменены. Удалены боевые и прочие
ненужные анимации, бинарные данные упакованы заново без сжатия и внешних декодеров.
Обе модели вместе занимают около 1.23 МиБ; каждая меньше 640 КиБ.

Источник: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
Ревизия: `672074b73ba276876a19e8816ecdc5241817ab47`.
Исходные файлы: `addons/kaykit_character_pack_adventures/Characters/gltf/{Mage,Rogue}.glb`.
Лицензия автора сохранена без изменений в `LICENSE.txt`.
Локальные URL, размеры, SHA-256 и имена клипов — в `manifest.json`.

## Подключение Юрой (G4)

- Загружать `/assets/characters/mage.glb` или `/assets/characters/rogue.glb`
  через существующий `useGLTF`. Все ресурсы внутри GLB, интернет не нужен.
- Для каждого экземпляра клонировать скелет через `SkeletonUtils.clone` (или
  поддерживающий скелеты `Clone`), иметь отдельный AnimationMixer/useAnimations.
  Нельзя переиспользовать один изменяемый скелет для нескольких NPC.
- `anim`: idle → `Idle`, walk → `Walking_A`, run → `Running_A`.
- `pose` имеет приоритет: lie → `Lie_Idle`, sit → `Sit_Floor_Idle`.
  Это готовые анимации поз: дополнительно поворачивать всю модель на 90° или
  опускать сидящего персонажа, как в текущем Character из примитивов, не нужно.
- Дополнительные жесты: `Interact`, `Cheer`. Отдельного взмаха рукой нет;
  `Cheer` — жест радости. Отдельных crouch/carry в этой выборке также нет.
- При интеграции выставить масштаб под игровой рост и уровень стоп по bounding
  box в Idle; проверить направление взгляда относительно игрового rotY.
  Перемещение персонажа остаётся под управлением клиента/сервера.
- `color`: материалы используют цветную текстуру. Клонировать материал перед
  изменением tint, иначе перекрасятся все экземпляры; tint умножает цвета текстуры.

Данные NPC и контракт не изменены: выбор модели и подключение в Character — G4
Юры. N5 предоставляет ассеты и анимации, сам по себе не заменяет персонажей в игре.

## Воспроизведение и проверка

Скачать исходные Mage.glb и Rogue.glb из указанной ревизии в отдельный каталог,
затем `node world/scripts/prepare-characters.mjs <каталог>`.
`npm run test -w world` проверяет бюджет, автономность GLB, встроенные PNG,
загрузку скелета и всех семи клипов через GLTFLoader и AnimationMixer Three.js.
В тесте отключено декодирование текстур (в Node нет браузерного декодера);
это не заменяет визуальную проверку после подключения G4.
