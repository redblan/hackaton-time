# shared — общий код (зона лида)

Этим пользуются все фичи. Любая правка здесь может сломать чужую работу.

- Если ты не лид — **не меняй файлы в этой папке**. Используй то, что есть, или скажи человеку, чего не хватает.
- Если правка всё-таки нужна: только **добавлять** (новый компонент, новый параметр с дефолтом), не менять поведение существующего.
- После любой правки: `npm run check` и `npm run build`.
