# Фичи

Ты работаешь внутри фичи. Каждая папка здесь — отдельная фича со своим владельцем.

- Трогай только папку своей фичи и её роуты в `src/app/(app)/<фича>/`.
- Эталон — `example/`. Новая фича: `npm run new:feature -- <имя>`, потом переделка под задачу.
- Переделка образца под тему, по порядку:
  1. `constants.ts` — справочники и подписи
  2. `schema.ts` — поля таблицы, затем `npm run db:push`
  3. `queries.ts`, `actions.ts` — под новые поля
  4. `components/`, `pages/` — тексты и колонки
  5. `npm run check`
- Нужны данные другой фичи — импортируй её `queries.ts`, но не меняй его. Нужна новая функция там — попроси владельца.
- `_registry.generated.ts` генерируется автоматически. Не редактировать.
